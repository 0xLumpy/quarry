# Accepted decisions

These records preserve product choices that remediation must not silently reverse:

- [`ADR-039-01`](ADR-039-01-broad-nuclei.md) — broad active Nuclei verification;
- [`ADR-039-02`](ADR-039-02-private-address-reach.md) — default private-address reach;
- [`ADR-039-03`](ADR-039-03-public-interactsh.md) — public Interactsh as the default OOB backend; and
- [`ADR-039-04`](ADR-039-04-scale-budgets.md) — scale-oriented, potentially long execution budgets.

An accepted decision fixes intent, not implementation status. Current conformance belongs in the
[current-HEAD ledger](../../audit/CURRENT-HEAD.md) and release evidence belongs in the
[release ledger](../../releases/v0.3.10.md).
